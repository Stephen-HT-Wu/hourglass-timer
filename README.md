# Hourglass Timer

A Chrome extension that provides a beautiful hourglass timer with real-time sand animation.

## Features

- Animated hourglass with falling sand effect (Canvas)
- Preset durations: 1 / 3 / 5 / 10 / 15 / 25 minutes
- Custom duration up to 120 minutes
- Start / Pause / Reset controls
- System notification when time is up

## Installation

1. Open `chrome://extensions/` in Chrome
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked**
4. Select the `hourglass-timer` folder

## Screenshot

After loading the extension, click the hourglass icon in the toolbar to open the timer popup.

## Tech Stack

- Manifest V3
- Canvas API for sand animation
- Chrome Notifications API
